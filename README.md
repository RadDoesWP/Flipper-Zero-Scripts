Hey, I'm RadDoesWP (Radoslav Ivanov) — welcome to my Flipper Zero Scripts repository! This is where I collect, build, and refine scripts for my Flipper Zero, built around my homelab and the things I pick up while learning about security and automation.

📖 About This Repository

This repository is a growing collection of BadUSB payloads and DuckyScript automation written for the Flipper Zero. The scripts range from simple keystroke injection demos to more involved automation routines, all built and tested in my own homelab environment.

The goal isn't just to dump code — it's to document what I learn along the way, keep a reliable set of tools I can reuse, and give anyone curious about the Flipper Zero's BadUSB capabilities a practical starting point.

📂 What's Inside

The repository is organized by category so you can find what you need quickly:

/badusb — Core BadUSB payloads and DuckyScript files. This is the main focus of the repo: keystroke injection scripts for automating repetitive tasks, testing input handling, and exploring how BadUSB attacks work in practice.
/homelab — Scripts written specifically for my homelab setup: things like automating configuration tasks on lab machines, speeding up repetitive setup steps, and general tooling I use to manage my own test environment.
/pentesting — Scripts geared toward practicing offensive security concepts in a controlled, ethical setting. These are meant for learning and practice on systems you own or have explicit permission to test.
